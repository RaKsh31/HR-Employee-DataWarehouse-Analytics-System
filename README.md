# HR-Employee-DataWarehouse-Analytics-System

## Project Overview
This project is developed using:
- Informatica Intelligent Cloud Services (IICS)
- Snowflake
- Power BI

The system performs ETL operations on HR datasets such as:
- Employee
- Department
- Attendance
- Payroll

## Features
- Data extraction from CSV and Oracle
- Data transformation using Informatica mappings
- Lookup, Filter, Rank, and Expression transformations
- Data loading into Snowflake tables
- Interactive Power BI dashboards

## Tools Used
- Informatica IICS
- Snowflake
- Power BI
- Oracle SQL
- GitHub

## Project Structure
- datasets/ → Input CSV files
- mappings/ → Mapping screenshots
- sql/ → SQL scripts
- powerbi/ → Dashboard screenshots/files
- docs/ → Documentation
